About Me

Careful work matters.

I’m Michael, a Data Analyst with a background in Economics & Statistics from University of Benin.

I didn’t start out calling myself a Data Analyst. For a long time I was the person people called when their Excel sheet wasn’t adding up, when reports had different numbers in different places, when a file had 5 ways of writing the same department.

I learned to like that part. The inspection. The cleaning. The part where you sit with a messy file and make it make sense.

During my NYSC at the Ministry of Trade and Industries in Uyo, that’s all I did. I managed over 50 personnel datasets, built monthly reports that management actually waited for, created validation checks because accuracy wasn’t optional, it was the whole job. And when the manual cleaning became too much, I started writing small Python scripts to do it faster and cleaner.

I’m comfortable in Advanced Excel, but I now use Python (Pandas) a lot more because it lets me build cleaning processes that can be reused next month, not just fixed once.

I’m open to opportunities where this kind of careful work matters — Data Analyst, MIS Officer, Operations Analyst — especially in banking and financial services.

Featured • 1,000+ Rows

HR Data Cleaning & Preprocessing Pipeline

A synthetic but very realistic HR dataset with 1,000+ rows and 13 columns. It was designed to be messy on purpose, like the files you actually get at work.

What was messy: Department_Region stuck together, Join_Date in multiple formats, Salary with "N/A" as text, missing Ages, inconsistent Status/Performance_Score, duplicate records.

What I did: Inspected first (shape, info, nulls, duplicates, value_counts), then built a reusable pipeline: cleaned column names, split Department_Region, fixed dates, converted Salary/Age to numeric, standardized text, removed duplicates, logged before/after.

Result: Clean, analysis-ready dataset with correct types and 2 new useful columns — plus a script that works for next month too.

How I Work

How I approach data work.

1. I Inspect First

I don’t jump into cleaning. I check shape, data types, missing values, duplicates, and category counts.

2. I Clean to Reuse

I fix columns first, then types, then values. I write code that can work on next month’s file.

3. I Report Clearly

I like reports that a non-technical manager can read and trust without asking "is this number correct?"
